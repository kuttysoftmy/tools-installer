# Contributing

Thanks for your interest in contributing to `tools-installer`.

## How to contribute

1. Fork the repository.
2. Create a feature branch for your change.
3. Keep changes focused and test them where applicable.
4. Open a pull request with a clear description of what changed and why.

## Contribution guidelines

- Keep scripts readable and menu labels clear.
- Prefer small, targeted pull requests.
- Document user-facing behavior changes in `README.md`.
